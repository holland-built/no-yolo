# The words I use with you

One word for one thing. Left column is the word I must not use on its own.
Right column is what I say instead.

The check reads the left column. Any word there blocks my reply.

To add a word: add a row. To let a word through: delete its row.
A word inside `backticks` never counts, so I can still name a command you type.

| Do not say | Say this |
|---|---|
| hook | the check |
| output style | the writing style |
| plugin | an add-on |
| marketplace | the list add-ons come from |
| skill | a command |
| subagent | a helper I run |
| repo | your project |
| commit | a saved version |
| push | send it to GitHub |
| merge | join one file into another |
| symlink | a shortcut to a file kept somewhere else |
| frontmatter | the settings at the top of a file |
| regex | a text search |
| grep | search |
| transcript | today's conversation |
| vault | your notes folder |
| compact | clear room in what I hold |
| context window | how much I can hold at once |
| language server | a tool that finds where a name is defined |
| idempotent | safe to run twice |
| deprecated | replaced, do not use it |
| invoke | run |

## Words that stay

These are plain English and I keep using them: file, check, list, test, run,
install, settings, table, command, add-on, project.

## Where this came from

The words above are the ones I actually used on you today, counted from the
conversation. Not a guess.

I also pulled the real dictionary for the standard we follow: 1210 words it does
not approve, each with a replacement. It did not fit. That dictionary is written
for aircraft manuals, so it swaps *file* for *remove* and *hook* for *put*.
Using it would have made my replies worse. I kept its rules and dropped its
word list.
