# no-yolo

Agent skill configuration for this repo.

`docs/agents/` tells the engineering skills three things:

| File                | What it records                          |
| ------------------- | ---------------------------------------- |
| `issue-tracker.md`  | Issues live in GitHub Issues, via `gh`   |
| `triage-labels.md`  | The five triage label strings            |
| `domain.md`         | Where `CONTEXT.md` and the ADRs live     |

Edit those files directly to change the setup.
