# Web work

One column. One typeface. One accent colour. A real headline and one action per screen.
Motion only in answer to a click. Mobile width first. No card grids, no eyebrow labels,
no arrows on buttons, no gradient hero.

Landing pages that convert are not the ones with the best animation.

## Before showing me a page

Open it in Chrome, screenshot it, and read the screenshot. Fix what you see there, not
what you intended to write. Then show me one page, not three variations.

This is not optional and it is not satisfied by describing what the page would look like.
A page you have not looked at is a page you have not finished.
