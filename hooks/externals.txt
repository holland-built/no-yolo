# Every external tool this repo tells anyone to install, with where it comes from.
#
# WHY THIS FILE EXISTS. On 2026-08-21 a rebuild published seven install references. Six were
# wrong: four GitHub repos under an owner who does not own them, one npm package under a name
# that is not its published name, and one, cxpak, that has never existed under any name, with a
# build stage written to run it. Nothing caught it, because nothing checked. The reference that
# a session writes and the package that exists are two different facts, and only one of them
# was ever recorded.
#
# WHY PROVENANCE AND NOT JUST EXISTENCE. "The name resolves" is a weaker claim than it looks.
# Names get squatted, abandoned, and transferred, and a package that exists under the right
# name can still be the wrong project. So each npm entry pins the GitHub repository its
# published metadata must point at, and hooks/external-check.sh compares them.
#
# FORMAT, one per line:
#   npm  <package>       <owner/repo its repository.url must contain>
#   gh   <owner/repo>    -
#
# Adding a row is a deliberate act: query the registry first (CLAUDE.md rule 5), then write
# what you saw. hooks/external-check.sh fails when a tracked install command names anything
# absent from this file, so an invented name cannot reach a commit.
#
# THREE FIELDS, AND NO FOURTH. This file answers one question, "does this name exist and does
# it still belong to who we said", and hooks/external-check.sh parses it with
# `read -r kind name want`. A fourth column is swallowed into $want and silently breaks the
# provenance comparison against an npm package's published repository.url, which is the check
# that catches a real-but-wrong package. Whether a piece is actually ON THIS MACHINE is a
# different question with a different granularity, and it lives in hooks/installed.txt:
# `mattpocock/skills` is one row here and four separate skills there.
#
# AN IDENTITY HERE MUST NOT BE IN hooks/retired.txt. Nothing is current and retired at once,
# and verify.sh goes red when one is in both. `bitjaru/styleseed` sat in both files from its
# retirement on 2026-08-25 until the same day, current by this file's own definition while
# retired by the other's.
