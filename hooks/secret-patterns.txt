# hooks/secret-patterns.txt — the ONE credential rule set in this repo.
#
# ONE READER, ONE ENGINE. hooks/secret-scan.sh is the only thing that ever reads this
# file. Nothing else loads it, and it is never handed to git grep: git grep and grep -E
# do not agree (the word-boundary escape matches NOTHING under git grep on macOS), and a
# rule set that behaves differently per reader is exactly how a scan goes blind while
# still reporting "clean". One file, one loader, one engine.
#
# NO WORD-BOUNDARY ESCAPES ANYWHERE. Engine-dependent — this repo was burned by one.
# The scanner's lint refuses to run if it finds one. Use explicit character classes.
#
# A NON-COMMENT LINE WITH NO REGEX METACHARACTER IS A LEAKED VALUE, NOT A RULE.
# A bare literal here means someone pasted the thing instead of its shape. The scanner
# rejects the whole file on sight and prints line numbers only, never the line.
#
# NEVER PASTE A REAL CREDENTIAL INTO A COMMENT HERE EITHER. This file is excluded from
# the enforcement scans (its rules self-match every one of them), so a value parked in a
# comment would hide here forever. The scanner therefore lints its own comments against
# its own rules and refuses to run on a hit. Not circular: comments are not rules.
#
# DELIBERATELY NOT sha256-PINNED, unlike the probe fixtures. This file is MEANT to
# change — every new vendor format lands here. Pinning it would train the reflex of
# updating a hash to make a check go green, which is the habit that makes the pinned
# fixtures worthless.
#
# Format: one extended-regex rule per line. Blank lines and # comment lines are ignored.

# ---- guarded words (5) ----
# A giveaway word next to a value. Ported from the health skill's inline grep, with its
# whitespace escapes replaced by POSIX classes (portable across both greps) and a LENGTH
# FLOOR added to every rule. The floor is mandatory: the unguarded word-then-[=:] form
# matches the pinned clean fixture's example-config line, which would turn the negative
# control red and take the "clean ignored" count with it.
