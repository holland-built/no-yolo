What you have

Yours

/build
Takes an idea. Asks you questions. Waits for your yes. Codex attacks the plan. Then it builds and tests. It only draws a mockup for web work.
/ship
Codex reads your change and tries to break it, then it pushes to GitHub. It updates docs only where the change made them wrong. If Codex is missing or fails, it says so and ships anyway.
/claude-video
Watches a video. Writes the notes into your Obsidian vault.
/claude-doc
Reads a PDF, Word, Excel, PowerPoint or EPUB file. Answers from it. Writes the notes into your Obsidian vault.
/last-30
Finds what moved on a topic in the last thirty days. Writes the answer into the repo so nobody searches twice.
/word-list
Reads your own saved conversations. Finds the words I lean on that you never say back. Writes them into the list the check reads, so my replies drop them.

Working quietly

Your rules
Answer first. Under ten lines. Say "I don't know" rather than guess.
The check
Reads every reply before you see it and sends it back if it breaks a rule. It stops a reply that runs long, names too many things, runs a sentence past twenty words, uses a word from your list, sounds machine-made, offers to help instead of helping, or excuses something without proof. It also stops me quitting mid-job, but only when I wrote a finish line down first.
The writing rules
Plain English on every reply, never only when you ask. Say what a thing does, not what it is called. One word for one thing. A table instead of paragraphs.
Your word list
One table of the words I must not use, and the plain word to use instead. The check reads it, so you change the list and never touch the check. It was built by counting the words I actually used on you.
Web rules
One column. One typeface. One accent colour. They only wake up when a web file is open.
Memory
When you correct me, it is saved. Things you have said plainly change how I work.

Giving it to someone else

The talking part alone
Two commands install the writing rules, the word list and the check on anyone's machine. Their own word list wins if they have one.
The whole thing
One script copies all eleven files and leaves anything of theirs untouched. Do not do both, or the check runs twice.
