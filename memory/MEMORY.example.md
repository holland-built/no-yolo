# Memory index

One line per fact. The content lives in `facts/`; this file is the only part loaded into a
session, so it stays a list of hooks.

Rules for what earns a file, and the shape of one: `docs/MEMORY.md`.

This is the tracked template. Your real index is `memory/MEMORY.md`, which git ignores for
the same reason it ignores `facts/`: both name things about you. Copy this file to
`memory/MEMORY.md`, then add a line per fact in the shape of the commented example.
